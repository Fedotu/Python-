## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов (3.14.2)
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером (4.39.0)
3. **Pytest**: Фреймворк для написания и запуска тестов (9.0.2)
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов
   - Allure: 2.38.0
   - allure-pytest: 2.15.3
5. **webdriver-manager**: Автоматическое управление драйверами браузеров

### Браузер:
**Firefox**: Браузер для тестирования (148.0.2)
**GeckoDriver**: Драйвер для Firefox (0.34.0)

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python)
- Используются docstrings для документирования методов и функций
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов

## Инструкция по запуску тестов для формирования отчета Allure

1. Убедитесь, что Firefox установлен:
   ```bash
   firefox --version
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --alluredir=./allure-results
   ```

   Эта команда запустит все тесты и сохранит результаты в директорию `./allure-results`.

---

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Общая статистика**: Количество пройденных, упавших и пропущенных тестов
   - **Название теста**: Например, `Тестирование покупки одежды`.
   - **Описание теста**: Заказ товаров левого столбца и сравнение цены.
   - **Шаги теста**:
     - Открыть сайт магазина
     - Ввести логин, пароль и нажать 'login'
     - Выбрать все товары слева
     - Нажать на иконку корзины
     - Нажать кнопку 'checkout'
     - Ввести данные пользователя
     - Нажать кнопку 'continue'
     - Получение итоговой суммы
     - Проверка соответствия ожидаемой и фактической цены.
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.
